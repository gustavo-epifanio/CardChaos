# Card Chaos

A strategic card game built with Python, featuring three elemental forces: Fire, Water, and Ice.

## About the Project

Elemental Cards is a personal project created to practice Python programming and develop problem-solving skills through game development.

The game combines strategic decisions, elemental advantages, and a scoring system in which players compete to reach victory using their cards.

This project is being developed incrementally as I expand my knowledge of Python and software development.

## Game Rules

The game is built around three elements:

- **Fire** beats Ice.
- **Ice** beats Water.
- **Water** beats Fire.

Each elemental card has a numerical value from 1 to 12. When two cards of the same element are played, the card with the higher value wins the round.

The deck contains 38 cards, including 36 elemental cards and 2 special Joker cards.

Jokers introduce a special mechanic that can affect the opponent's score.
